# ChatChamps Backend

ChatChamps is a chatbot creation platform where users can build and manage AI-powered chatbots.  
This is the backend built using **Node.js, Express, and MongoDB**.

---

## 🚀 Features
- User authentication (Register / Login with hashed passwords)  
- Create & manage chatbots  
- Store chatbot configurations in MongoDB  
- REST API integration (used by Android frontend with Retrofit)  

---

## 🛠️ Tech Stack
- Node.js  
- Express.js  
- MongoDB (Mongoose)  
- JWT Authentication  
- Bcrypt for password hashing
